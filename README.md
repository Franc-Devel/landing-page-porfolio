# FAUVOR · Landing y demos de productos

Sitio de presentación de FAUVOR, compañía tecnológica integral. Incluye Finanzas, Taller, Analytics, Gaming, Clima y Flow, con identidad marfil, bronce y dorado y recursos originales del kit.

## Ejecutar

Es una web estática, sin dependencias de compilación:

```bash
python3 -m http.server 8080
```

Abrí `http://localhost:8080`. No subas datos ni credenciales de producción a las demos.

FAUVOR Flow reemplaza la tarjeta de FAUVOR Studio: es una aplicación de automatización con flujos, tareas, historial y reintentos. Su demo usa reglas locales y almacenamiento del navegador, sin llamadas a IA ni envíos de Telegram. El servidor y sus integraciones opcionales están en el repositorio del producto.

Las portadas son ilustraciones conceptuales, no capturas de las aplicaciones. Cada repositorio documenta las capacidades reales y las diferencias respecto de su demo. Las interfaces no comparten automáticamente datos ni cuentas.

## Publicación

La publicación en Sites se realiza desde un checkout de hosting separado y conserva el acceso restringido a las cuentas autorizadas. Este repositorio no contiene credenciales ni la identidad del entorno de hosting. Un push a GitHub no implica que Sites se actualice automáticamente.
