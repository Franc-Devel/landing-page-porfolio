## 🎯 Enfoque y Criterio de Desarrollo

1. **Fullstack & APIs Modulares:**
   Servicios backend ordenados con Node.js, Express y Prisma ORM. Contratos REST consistentes, validación estricta y modelos relacionales tipados.
2. **Frontend Reactivo & UX Limpio:**
   Interfaces modernas y livianas con React y CSS nativo. Cero bibliotecas innecesarias, carga veloz y navegación diseñada para descansar la vista.
3. **Análisis de Datos con Python:**
   Tratamiento estructurado y saneamiento de información con Python y Pandas, orientando los datos a métricas reproducibles y comprensibles.

## 🚀 Ejecución Local

Para visualizar el portafolio en un entorno local:

```bash
# Servir con cualquier servidor estático (ejemplo con Python):
python3 -m http.server 8080

# O con npx:
npx -y serve .
```

Abre en tu navegador: `http://localhost:8080`
